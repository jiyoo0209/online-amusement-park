# 온라인 놀이공원

지금 접속한 사람들과 같은 놀이공원에서 노는 웹 3D 멀티플레이 놀이공원이에요. 같은 놀이기구에 타면 서로 옆자리에 앉은 게 보여요.

**바로 들어가기:** https://jiyoo0209.github.io/online-amusement-park/

## 놀이기구
- **🎢 롤러코스터**: 체인 리프트로 28m까지 올라갔다가 떨어져요. 최고 시속 약 80km. 레드 레이서 열차 4칸에 16명까지 탈 수 있어요
- **🏴‍☠️ 바이킹**: 점점 크게 흔들리다가 거의 수평까지 올라가요. 18명까지 탈 수 있어요
- **🎠 회전목마**: 위아래로 움직이는 목마 16마리가 있어요
- **🎡 대관람차**: 계속 도는 유리 캡슐 곤돌라 12개. 아래에 곤돌라가 오면 타고, 한 바퀴(72초) 돌면 내려요
- **🗼 자이로드롭**: 한 바퀴 돌면서 37m까지 올라간 뒤, 몇 초 멈췄다가 수직으로 떨어져요

놀이기구를 고르면 좌석 배치도가 떠요. 원하는 자리를 고르면 그 자리에 앉고(대관람차는 곤돌라를 골라요), `아무 자리나`를 누르면 남는 자리에 앉아요. 다른 사람이 앉은 자리는 고를 수 없고, 출발 전이면 `💺 자리` 버튼으로 자리를 바꿀 수 있어요.

놀이기구는 운행 시간표대로 돌아가요. 탑승 시간에 맞춰 가면 바로 타고, 운행 중이면 입구에서 줄을 서요. 다음 탑승이 시작되면 자동으로 타요. 운행이 끝나면 자동으로 내려요.

## 조작
- 바닥을 누르면 걷기, 놀이기구를 누르면 그 놀이기구 입구로 가기, 벤치를 누르면 앉기
- 롤러코스터와 바이킹은 계단으로 승강장에 올라가서 타요 (놀이기구를 누르면 계단을 거쳐 알아서 걸어가요)
- 왼쪽 아래 🎢 버튼으로 놀이기구 목록 보기 (남은 시간, 타고 있는 사람 수)
- 휴대폰은 왼쪽 아래 조이스틱으로 걷기, PC는 WASD 또는 방향키 (Shift를 누르면 빨리 걷기)
- 드래그로 둘러보기, 휠이나 두 손가락으로 확대·축소
- 타는 동안에는 `시점` 버튼으로 탑승 시점과 밖에서 보기를 바꿀 수 있어요
- 간식 가게(솜사탕·츄러스·풍선·아이스크림·핫도그)에서 간식을 사서 들고 다닐 수 있어요
- 이모지 버튼으로 머리 위에 이모지 말풍선을 띄울 수 있어요
- 오른쪽 위 카메라 버튼으로 사진 찍기 (폴라로이드 또는 원본). 휴대폰은 `공유하기`로 바로 보내고, 컴퓨터는 `복사하기`를 누른 뒤 대화창에 Ctrl+V(맥은 ⌘V)로 붙여넣어요
- 서울 시간에 맞춰 낮, 노을, 밤으로 바뀌어요. 밤에는 놀이기구에 불이 켜져요

## 멀티플레이 구조
- 실시간 접속은 Supabase Realtime(`online-amusement-park` 프로젝트)이 맡아요.
  - Presence: 접속자 목록, 이름, 외형
  - Broadcast: 위치, 앉은 벤치, 탄 놀이기구와 좌석, 손 흔들기, 이모지, 들고 있는 간식
- **모든 놀이기구는 시계로 움직여요.** 위치를 주고받지 않고, 모든 화면이 같은 시각에 같은 계산을 해요. 그래서 위치를 주고받는 양이 적은데도 같은 열차에 탄 사람이 정확히 같은 자리에 보여요.
- NPC는 간식 가게 직원 한 명뿐이에요. 놀이기구에는 접속한 사람만 타요.
- 캐릭터는 카페 프로젝트와 같은 치비 캐릭터예요 (`assets/chars/`: 몸·헤어 10종·옷 5종). 헤어, 머리색, 옷, 신발은 숫자 하나(seed)로 정해져서 모든 화면에 같은 모습으로 보여요.

## 폴더 구성
```
src/index.html     화면 구성(HTML·CSS)
src/js/00-core.js  공통 도구, 렌더러, 재질
src/js/10-world.js 하늘·조명·땅·광장·정문·나무·가로등·벤치·간식 가게
src/js/14-model-utils.js 놀이기구 모델 공용 도구 (반사 환경, 재질별 합치기)
src/js/15-coaster-car.js 롤러코스터 열차 모델
src/js/16-wheel-gondola.js 대관람차 유리 캡슐 곤돌라
src/js/20-rides.js 놀이기구 5개 (모양, 운행 시간표, 좌석)
src/js/30-avatars.js 캐릭터, 이름표, 포즈, 간식
src/js/40-play.js  조작, 탑승, 하단 메뉴, 소리
src/js/42-seatpick.js 자리 고르기 (좌석 배치도)
src/js/45-npc.js   간식 가게 직원(NPC)
src/js/47-photo.js 사진 모드 (찍기, 저장, 공유·복사)
src/js/50-net.js   실시간 접속, 입장 화면, 메인 루프
build.mjs          src → dist 빌드
```

## 개발
```bash
npm install
npm run dev        # 빌드 후 http://localhost:8080
```
- `?room=local`을 붙이면 서버 없이 같은 브라우저의 탭끼리 멀티플레이를 시험할 수 있어요.
- `?t=day`, `?t=sunset`, `?t=night`를 붙이면 시간대를 고정해서 볼 수 있어요.

## 배포
`main`에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 `npm ci`와 `npm run build`를 실행하고 `dist/`를 GitHub Pages에 올려요. 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있어요.

## 참고
- Supabase 무료 프로젝트는 1주일 동안 활동이 없으면 일시정지돼요. 그러면 Supabase 대시보드에서 다시 켜면 돼요.
- `src/index.html`에 들어 있는 Supabase 키는 웹페이지용 공개(anon) 키예요. 노출되어도 괜찮아요.
